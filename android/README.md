# UUU Flash — прошивка панелей i.MX8M Plus с Android-телефона

Android-версия uuu-gui: та же NXP `libuuu` (тег `uuu_1.5.243`), тот же порядок
прошивки, что пресет `EmmcAll4G` настольного приложения. Телефон работает USB-хостом,
root не нужен.

Проверено: Samsung Galaxy Fold (Android 17), Realme Neo 7.

## Как пользоваться

Краткая инструкция есть в самом приложении — иконка ⓘ в шапке (`Help.kt`).

1. Телефон → OTG-переходник USB-C → USB-A → панель.
2. Панель в режиме прошивки (SDP): выключить питание, зажать скрытую кнопку, включить.
3. «Выбор загрузчика» — `imx-boot-pm-<машина>…`, «Выбор прошивки» — `…wic.zst` той же машины.
4. Память 4 ГБ или 2 ГБ. Не знаете — «Проверка без записи»: загрузчик не того объёма просто не стартует.
5. «Прошить панель». Идёт в фоне, ход — в уведомлении.

## Порядок прошивки

```
SDPS: boot  imx-boot_4G.bin (или 2G)   ← вшитый универсальный загрузчик → RAM → fastboot
FB:   flash -raw2sparse all  <образ>.wic.zst/*
FB:   flash bootloader       imx-boot-pm-<машина>…
FB:   mmc partconf …
(fastboot reboot — если включено «Перезагрузить после прошивки»)
```

Почему так: ROM панели не сообщает объём памяти, а универсальный загрузчик собран
под фиксированный объём. Загрузчик платы объём определяет сам, но по USB панель с
ним не стартует — он только пишется в eMMC.

## Устройство

| Файл | Что делает |
|---|---|
| `cpp/CMakeLists.txt` | Собирает libuuu и зависимости (libusb, zstd, bzip2, tinyxml2) из исходников, скачиваемых с проверкой SHA256. OpenSSL не нужен. |
| `cpp/uuu_android_usb.*`, `uuu_android_redirect.h` | libuuu ищет устройства через `/dev/bus/usb`, а без root его нет. Kotlin передаёт fd из `UsbManager`, мы оборачиваем его `libusb_wrap_sys_device` и подменяем 5 вызовов libusb в `usbhotplug.cpp`/`trans.cpp` через `-include`, без правки исходников libuuu. |
| `cpp/uuu_android_file.*` | Файл, выбранный в проводнике, читается без копии: путь `/uuufd/<fd>/<имя>`, `stat64`/`open` в `buffer.cpp` превращаются в `fstat`/`dup`. |
| `cpp/uuu_android_http_fix.h` | `base64_encode` для `http.cpp` без OpenSSL (в upstream она под `#ifdef UUUSSL`). |
| `cpp/uuu_jni.cpp` | JNI: устройства, запуск скрипта, события libuuu в Kotlin. |
| `FlashService.kt` | Foreground-сервис в отдельном процессе `:flash`: libuuu — один запуск на процесс, после каждого запуска процесс завершается. |
| `UsbLink.kt` | Разрешения USB, `claimInterface(force)` (снимает `usbhid` с ROM), передача fd в libuuu, `fastboot getvar/reboot` напрямую. |
| `FileCheck.kt` | Проверка выбранных файлов по содержимому: загрузчик — заголовок IVT i.MX8M; прошивка — образ диска `.wic(.zst/.bz2/.gz)`. |
| `MainActivity.kt` | Экран. Палитра — из фронта панелей, тема светлая/тёмная по системе. |
| `probe/` | Проба USB-хоста на Kotlin без libuuu (первая проверка телефонов). |

## Грабли, на которые уже наступили

- **Сжатый образ писался без распаковки (0.6–0.8).** libuuu сначала пробует `<образ>.wic.zst/*` как обычный файл (`FSFlat` — первый в `FS_DATA`, `buffer.cpp`); на настоящем пути `stat()` падает, и файл уходит распаковщику. Подмена `/uuufd/…` не проверяла хвост и принимала такой путь за файл — на eMMC уходили сжатые байты, панель не загружалась. Исправлено в 0.9: путь должен заканчиваться именем. Признак в логе: «записано N из N МБ», где N — размер сжатого файла. Теперь это ловится и помечается ошибкой.
- **Разрешение USB.** После «Открыть UUU Flash? → Всегда» Android выдаёт разрешение сам при каждом подключении; иначе — диалог. `openDevice` сразу после подключения иногда возвращает null — повторяем.
- **Почему не веб и не iPhone.** WebUSB не даёт захватывать HID, а ROM i.MX — HID; WebHID на Android нет. iOS не даёт приложениям доступ к USB-устройствам без MFi.

## Сборка

Нужны JDK 17+, Android SDK (platform 36), NDK `28.2.13676358`, CMake `3.31.6`.

1. **Универсальные загрузчики** `imx-boot_2G.bin` и `imx-boot_4G.bin` положить в
   `app/src/main/assets/boot/`. В git их нет — это внутренние бинарники; без них
   сборка остановится с подсказкой.
2. **Ключ подписи** — в `~/.gradle/gradle.properties` (не в репозитории):
   ```
   UUUFLASH_STORE_FILE=/путь/к/uuuflash-release.jks
   UUUFLASH_STORE_PASSWORD=…
   UUUFLASH_KEY_ALIAS=uuuflash
   UUUFLASH_KEY_PASSWORD=…
   ```
   Обновление ставится поверх, только если подписано тем же ключом.
3. Сборка:
   ```sh
   export JAVA_HOME=… ANDROID_HOME=…
   ./gradlew :app:assembleRelease   # app/build/outputs/apk/release/app-release.apk
   ```
